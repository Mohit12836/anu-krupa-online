## 1. चरणबद्ध व्हाट्सएप एकीकरण (Phased Integration)

### WA-001 — वर्तमान चरण: आधिकारिक Click-to-Chat
* प्रोटोकॉल: `https://wa.me/916263879076?text=...`
* सुरक्षित व प्री-फिल्ड संदेश (सेवा का नाम, चुना गया विकल्प, ग्राहक टिप्पणी)।
* **स्पैम-मुक्त:** ग्राहक स्वयं अपने ऐप में संदेश देखकर स्वेच्छा से भेजता है।
* कोई अनधिकृत बॉट या वेब-स्क्रैपिंग नहीं — 0% नंबर बैन जोखिम।

### WA-002 — भविष्य का चरण: आधिकारिक Meta Cloud API (WACA)
* दैनिक 50+ संदेश होने पर आधिकारिक Meta WACA API का एकीकरण।
* सुरक्षित वेबहुक सत्यापन (HMAC-SHA256)।
* इंटरएक्टिव बटन्स व लिस्ट मैसेजेस।
* 24-घंटे की कस्टमर सर्विस विंडो का सख्त अनुपालन।

### WA-003 — ऑटोमेशन पाइपलाइन (Automation Flow)
1. ग्राहक का संदेश प्राप्त होना
2. इंटेंट वर्गीकरण (KCC / PAN / DL / स्थिति जांच)
3. स्वीकृत टेम्पलेट या लिस्ट विकल्प भेजना
4. आवश्यकता पड़ने पर संचालक (Human Escalation) को सूचित करना

### WA-004 — एरर हैंडलिंग व फॉलबैक
* अमान्य इनपुट पर विकल्प मेनू दिखाना।
* सिस्टम द्वारा उत्तर न मिलने पर संचालक के पास हैंडऑफ़।

### WA-005 — सहमति एवं गोपनीयता (Consent & Privacy)
* केवल सेवा संबंधी वार्तालाप; कोई अवांछित बल्क प्रचार नहीं।
