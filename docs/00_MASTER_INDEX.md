## 1. कोर स्थायी नियम (The 8 Permanent Laws)

| Rule ID | स्थायी नियम | विवरण |
| :--- | :--- | :--- |
| **R-01** | Amazon-Grade Discovery | 50+ डिजिटल सेवाएं, 3-भाषा सर्च (Hindi, English, Hinglish), व 1-टैप कैटेगरी नेविगेशन |
| **R-02** | Premium Design | Dark Navy `#091726`, Sunset Orange `#FF8A24`, WhatsApp Green `#16A34A`, एंबिएंट ग्लो |
| **R-03** | Mobile App-First | 1-हैंड नेविगेशन, बॉटम ऐप बार, 48px+ टच टारगेट्स, 0 हॉरिजॉन्टल स्क्रॉल |
| **R-04** | 100% WhatsApp-First | वेबसाइट पर Direct Calling पूरी तरह बंद; सभी इन्क्वायरीज़ आधिकारिक WhatsApp पर |
| **R-05** | No Misleading Claims | अनुपलब्ध सेवा को उपलब्ध नहीं दिखाना; कोई फ़ेक काउंटर या फ़ेक रिव्यू नहीं |
| **R-06** | 1–3 Tap Admin Simplicity | मालिक के लिए स्विच, चिप्स, और प्रीसेट्स द्वारा मोबाइल से 1-3 टैप में कंट्रोल |
| **R-07** | Voluntary Retention | ग्राहक संतुष्टि, स्वैच्छिक WhatsApp चैनल, उपयोगी रिन्यूअल अलर्ट्स |
| **R-08** | Strict Phase Gating | एक चरण पूर्ण व सत्यापित हुए बिना अगला चरण शुरू नहीं करना |
